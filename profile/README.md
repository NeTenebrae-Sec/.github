# [ NeTenebrae ] - Proyectos de Ciberseguridad y Sistemas

[![YouTube](https://img.shields.io/badge/YouTube-NeTenebrae-FF0000?style=for-the-badge&logo=youtube&logoColor=white)](https://www.youtube.com/@NeTenebrae)
[![Open Source](https://img.shields.io/badge/Open%20Source-%E2%9D%A4%20-blue?style=for-the-badge)](https://github.com/orgs/NeTenebrae-Sec/repositories)

Espacio de desarrollo e investigación para la creación de herramientas de código abierto, documentación técnica y recursos educativos enfocados en **Ciberseguridad**, **Programación**, **Sistemas Linux** y **Automatización**.

---

## > ÁREAS DE TRABAJO

El contenido y los repositorios distribuidos aquí se dividen en las siguientes líneas principales:

* **Seguridad Web & Pentesting**: Análisis de vulnerabilidades, pruebas de concepto y herramientas de auditoría.
* **Sistemas Linux & Scripting**: Automatización de tareas, administración de sistemas y entornos de trabajo orientados a la terminal.
* **Desarrollo de Software**: Herramientas y utilidades ligeras desarrolladas para resolver problemas concretos.
* **Formación y Laboratorios**: Material de apoyo, laboratorios prácticos y scripts explicados para la comunidad educativa.

## > CONTRIBUCIONES

Cualquier aporte al código o corrección en la documentación es bienvenido:

1. Haz un fork del repositorio de interés.
2. Crea una rama para tus cambios (`git checkout -b feature/mejora`).
3. Envía un Pull Request detallando los cambios propuestos.
